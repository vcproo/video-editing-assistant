# 镜头索引规范

以一个可预览的动效变体为一条记录，同卡多个变体分别记录。按 SKILL.md 的双文件 JSONL 格式交付。以库标识、模板卡名和变体名作为组合标识，重复核对时更新原条目。

每条记录包含：

- 模板卡、变体、来源与样片入口。记录核对日期，来源有版本时记录版本。
- 画面事实。记录开头构图、主体变化、运动方向、结束构图，以及显著的颜色、闪烁、运动强度和节奏。样片时长与实际建议时长分开。
- 叙事用途。用可筛选的标签表达观众要看懂的内容，例如「展示前后变化」「演示一次操作」「揭示结果」「强调数字」。记录适合的场景和不适合的场景。
- 素材条件。写明需要的输入、可替换的元素、必须具备的对应关系和已验证的限制。
- 搭配建议。写明可用什么画面起接、落点能留给下一镜什么主体或构图。把这些记录为剪辑判断。
- 核对状态。区分「已看样片」「仅核对文字」「待核对」。有运行条件时，以代表性真实素材验证用途和衔接，记录结果。

用实际动效核对画面事实。有必要时看起点、中段、终点，并连续播放检查速度与节奏。说明与样片不一致时，以样片记录观察结果并标出差异。仅看文字时保留出处及待核对标记，交付时披露；优先推荐已看过的变体。因样片不可用而无法确认的属性留空或标待核对。

例如，对「输入内容变成可操作卡片」的需求，可将 canvas-materialize-moves 中的 panel-to-canvas 作为候选。来源条目和结果卡片要可逐项对应。前镜可以让观众先读来源，后镜可以保留生成的卡片让人读详情。画面与实现仍需以对应样片核对。

作者偏好跟随作者或项目记录。将「作者不喜欢强闪白」用于这位作者的选镜，模板索引中只记录样片是否含明显闪白和有关的剪辑判断。维护全库时用源库的变体清单检查覆盖率，报告已核对、仅文字和待核对的数量，并记录失效链接。
